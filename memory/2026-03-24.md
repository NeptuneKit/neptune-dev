## 关键决策

- 全仓执行“成熟库优先”硬约束：SQLite / HTTP / CLI / 协议解析优先使用成熟库，不接受手搓基础设施实现。
- 对 Android 生态补充决策：`GRDB 7+` 作为 Swift-on-Android 路径可行，但当前 Kotlin/JVM SDK 主线优先 Ktor/Android 原生生态，避免跨语言桥接成本。
- v2 日志主链路保持 `/v2/*` + 长轮询（`afterId + waitMs`）作为跨端最小基线；WebSocket 不作为当前强依赖。
- `GET /v2/logs` 新增 `format=text` 作为可读输出选项，不改变既有 `json/ndjson` 行为。
- SDK 统一策略升级为“默认内存 + 可选持久化后端”，在不破坏既有 API 的前提下满足本地先落盘诉求。
- 父仓新增 GitHub Actions 集成 CI 入口，统一调用 `docs-linhay/scripts/run-all-checks.sh`，并保留 `workflow_dispatch` 的 Harmony 构建开关。
- 父仓统一发布编排采用 `workflow_dispatch` + 跨仓 token 触发子仓 `workflow_dispatch`，避免在父仓重复实现发布构建链路。
